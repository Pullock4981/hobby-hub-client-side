rsc# 🎨 Hobby Hub

**Hobby Hub** is a social platform that lets users explore, join, or create interest-based hobby groups. It's built with React, Tailwind CSS v4, DaisyUI, and Firebase for a smooth, modern user experience.

🌐 **Live Site**: [https://hobbyhub-4981.netlify.app/]

---

## 🚀 Features

- 🔍 **Explore Hobby Groups** — Browse a wide variety of groups based on interests like arts, sports, tech, and more.
- 🧑‍🤝‍🧑 **Join or Create Groups** — Easily join existing groups or create your own with detailed information and themes.
- 🌗 **Dark & Light Mode Toggle** — Seamlessly switch between light and dark themes using DaisyUI.
- 📊 **Animated Counters** — Interactive count-up stats for total groups, likes, comments, and more.
- 🔐 **Firebase Authentication** — Secure sign-in and user filtering for personalized group visibility.

---

## 🛠 Tech Stack

- **React** (v19)
- **Tailwind CSS** (v4.1.7)
- **DaisyUI** (v5.0.37)
- **Firebase Auth**
- **Vite** (build tool)
- **React CountUp**, **React Slick**, **SweetAlert2**, and more
